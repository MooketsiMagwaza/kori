# Code of conduct

Everyone working on Kori, and everyone using its channels, is expected to be respectful, patient
and honest, with each other and with the people and communities Kori serves.

- Be kind and specific in review. Criticise code and decisions, not people.
- Respect the knowledge of guides, rangers, farmers and park staff; Kori depends on it.
- Never share someone's location, trips or personal data outside the purpose they agreed to.
- Harassment, discrimination and intimidation are not tolerated, in any channel.

Kori follows the Contributor Covenant, version 2.1
(<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>). Report a problem privately
to the repository owner. Reports are handled confidentially, and the owner decides on the response,
from a private warning to removal from the project.

# Kori

Kori is an offline-first safari and wildlife app for Botswana, named after the
kori bustard (kgori in Setswana), the national bird.

This repository is at its first commit. The plan and the state of every piece
of work are kept in `docs/WORK_ORDERS.md` as it is added.
